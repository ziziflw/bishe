# 安全边界

应用以当前用户权限运行，Tauri capability 不是操作系统沙箱，SQLite 未加密。前端无文件系统、Shell、HTTP 插件权限；原生对话框在 Rust 内部调用。所有命令验证 ID、长度、枚举与授权。生产 CSP 禁止第三方脚本和网络连接。

只支持本地盘符绝对路径，保守拒绝 UNC、设备路径、父目录跳转、ADS、尾随点/空格和所有 reparse point（包括 symlink/junction/云文件占位符）。逐层打开目录句柄，检查 reparse 属性；持有不共享写入/删除的句柄直至元数据读取及数据库事务结束，降低检查后路径被替换的竞争风险。最终文件只读打开，不读取正文。范围按路径组件判断；授权根身份也必须相符。

路径和标签保存在本机 SQLite，界面可见，不写入日志。原文件不写入、不复制、不移动、不删除、不生成旁文件。Windows 自身可能管理最后访问时间，应用无法保证操作系统完全不改变访问时间；验证使用内容哈希、大小、修改时间、创建时间和目录清单。

丢失文件保留记录和标签；撤销授权后按需检查首先验证授权，不能以检查缺失为由绕过授权。重授权由用户再次选择完成。文件被其他进程以不兼容共享方式打开时保守报错。

身份标识不是密码学永久身份：卷克隆、恶意管理员、底层文件系统攻击或创建时间伪造不在本版防护范围。不同卷文件不能重新关联。数据库损坏/迁移失败时启动失败且不重建覆盖数据库。没有自动恢复或数据库加密，不声称完整沙箱。

## 本轮目录位置调整
用户明确要求改用 D 盘。工程、包缓存、构建输出和临时测试目录均在 `D:\PersonalFileTags`。应用采用便携式数据目录，启动位置必须可写；若不可写则报告错误，不回退到 C 盘。WebView2 运行时自身仍是系统已安装组件，不复制或移动系统工具。
