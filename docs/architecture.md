# V0.1 架构决定

Windows x64 / Tauri 2 / Rust / Vue 3 + TypeScript / Vite / pnpm / bundled SQLite。

界面只调用固定业务命令，不接收文件内容、不传入任意路径。Rust 原生对话框产生本次明确授权；Repository 负责迁移、参数化 SQL、事务、标签与查询；access 模块负责 Windows 路径、句柄、权限范围和文件身份。

按用户要求采用 D 盘便携布局：数据库及 WebView2 数据只写入 EXE 旁的 PersonalFileTags-data 专用目录；发布 EXE 放在 D:\PersonalFileTags\bin。开发构建在 D 盘 target 下使用各自数据目录。不会回退写入 C 盘 AppData。数据库外键开启、WAL、FULL synchronous、busy timeout；迁移在事务内执行，拒绝未知高版本。没有后台扫描、监控、自动遍历、网络请求或源文件写入功能。

文件身份采用卷序列号 + Windows 文件索引 + 创建时间，数据库 ID 是稳定业务引用。路径唯一约束防重复，文件身份唯一约束可识别同卷移动。原路径被新文件占用时拒绝覆盖记录。重新关联要求原身份匹配，不凭同名/大小猜测。跨卷移动和复制会改变身份，本版拒绝自动关联。

目录授权和文件授权独立。选择文件登记会建立持久文件授权；撤销一个授权不会撤销其他重叠授权。目录不遍历，只用于已登记文件后续按需检查。撤销与清除索引是两个独立操作；清除索引保留授权与标签词表。

未来处理服务只能通过受控业务边界领取用户授权的任务；本版不启动处理进程，不建立 AI、OCR、向量或任务队列模块。
